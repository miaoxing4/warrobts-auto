## 先读这个（3 分钟上手）

1. **这个游戏没有无障碍树**。`uiautomator dump` 只能拿到 5 个空 `FrameLayout`。
   → 所有自动化必须靠 **截图 + 视觉识别 + 坐标点击**。不要再尝试读 UI 元素。
2. **必须先锁横屏**，否则 `input tap` 坐标与截图坐标不一致（会错位）。
   锁定后两者**完全一致**（2400×1080）。
3. **验证任何改动，先跑** `python test_state_offline.py`（应 17/17 通过）。
4. **不要用固定坐标点广告角部按钮**——位置随广告版式变化，必须动态检测。
5. **战斗中绝不允许点"离开"**——只点"留在战斗中"，否则扣分。
